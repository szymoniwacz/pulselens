# Project Vision

## One-sentence vision

PulseLens collects application events and provides accurate, filterable analytics through an HTTP API and a web dashboard.

## Problem

Application operators need accurate event analytics without building their own ingestion and aggregation pipeline.

## Desired outcome

From a clean checkout, a reviewer can create a demo application, submit synthetic events, explore its activity and reproduce measurements on one million events.

## Non-goals

No public service, real personal data, user accounts, asynchronous pipeline or exactly-once delivery. Full boundaries: [scope](scope.md).
