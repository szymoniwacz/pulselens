# Project Vision

## One-sentence vision

PulseLens is a small Rails event analytics demo that helps a backend developer learn ClickHouse and explain design choices during recruitment.

## Problem

A portfolio needs demonstrable ingestion, correct analytics, clear storage boundaries and reproducible measurements rather than an oversized analytics platform.

## Desired outcome

From a clean checkout, a reviewer can create a demo application, submit synthetic events, explore its activity and reproduce measurements on one million events.

## Non-goals

No public service, real personal data, user accounts, asynchronous pipeline or exactly-once delivery. Full boundaries: [scope](scope.md).
